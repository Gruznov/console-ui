# @polyconsole/console-ui

## 0.7.0

These version notes describe the imported source baseline. They do not assert
that these versions are publicly available from the npm registry.

### Minor Changes

- Add router-neutral ActionLink controls, accessible Tooltip overlays, and dense
  FilterToolbar compositions for shared operational console workflows.

## 0.6.0

### Minor Changes

- Add native choice cards and bounded progress steps for dense setup, policy, and approval workflows.
- Add shared form fields, native inputs, selects, textareas, compact form grids, and action layouts for consistent internal console workflows.

## 0.5.0

### Minor Changes

- Add an opt-in collapsible desktop navigation rail to `ConsoleShell` with accessible controls, compact icon presentation, and unchanged mobile disclosure behavior.

### Patch Changes

- Allow vertical page scrolling to continue when the pointer is over a horizontally scrollable `DataTableFrame`.

## 0.4.1

### Patch Changes

- Keep DataTableFrame content at least as wide as its visible container while
  preserving the consumer-defined minimum width for narrow overflow.

## 0.4.0

### Minor Changes

- Collapse shell navigation behind an accessible compact toggle on narrow
  layouts while keeping the active destination visible in the compact header.

## 0.3.0

### Minor Changes

- Add truthful FeedbackState and dense InlineNotice foundations for operational
  checking, empty, unavailable, warning, success, and failure presentation.
- Add explicit compact-density and fluid-content shell modes, keep the existing
  defaults, and make desktop navigation independently scrollable.
- Add DataTableFrame for labeled, keyboard-focusable dense table overflow with
  consumer-owned minimum width, maximum height, and sticky-header policy.

## 0.2.0

### Minor Changes

- Add the product-neutral ConsoleShell, ConsoleIdentity, ConsoleNavigation, and ConsolePageHeader foundations for incremental consumer adoption, and keep the aligned package release line intact.

### Patch Changes

- Updated dependencies
  - @polyconsole/design-tokens@0.2.0

## 0.1.0

### Minor Changes

- Establish the initial Console UI package baseline with semantic tokens,
  compact accessible primitives, package CSS, typed ESM exports, and validated
  package artifacts.

### Patch Changes

- Updated dependencies
  - @polyconsole/design-tokens@0.1.0
